PRO PLANNER Privacy Policy

Last updated: May 26, 2026

PRO PLANNER is designed as a local-first planner. Most planner data is stored in the browser on the user's device unless the user chooses to sign in with Google for cloud sync.

Data Stored Locally

The app may store tasks, goals, habits, exams, notes, focus logs, templates, settings, reports, and backup/restore data in browser local storage on the user's device.

Cloud Sync

If Google login is enabled by the user, planner data is synced to Firebase Realtime Database under that user's account. Cloud sync is optional. The app remains usable without login.

Authentication

Google sign-in is used only to identify the user for cloud sync. The app does not sell personal information.

Notifications

If the user enables notifications, the app may show reminders, timer alerts, and exam alerts on the device. Notification permission can be disabled in browser or system settings.

Data Export, Restore, and Deletion

  • Users can export a backup file from the app.
  • Users can restore planner data from a backup file.
  • Signed-in users can delete cloud sync data from Settings.
  • Local data remains on the device unless the user clears browser/app storage.

Third-Party Services

The app uses Firebase services for optional authentication and cloud sync. It may also load browser libraries from Google Firebase and jsDelivr CDN when online.

Contact

For privacy or data deletion requests, use the support contact published with the app listing. A permanent support email and hosted policy URL should be added before public store release.
